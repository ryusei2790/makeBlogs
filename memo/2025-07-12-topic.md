### useStateの基本概念

useStateはReactの最も基本的なフックの一つで、関数コンポーネントで状態を管理するために使用されます。

```javascript
const [state, setState] = useState(initialValue);
```

### 配列の状態管理

配列の状態を更新する際は、直接変更するのではなく、新しい配列を作成する必要があります。

```javascript
// ❌ 間違った方法
const [items, setItems] = useState([]);
items.push(newItem); // これは動作しません

// ✅ 正しい方法
setItems([...items, newItem]);
// または
setItems(prevItems => [...prevItems, newItem]);
```

### オブジェクトの状態管理

オブジェクトも同様に、スプレッド演算子を使用して新しいオブジェクトを作成します。

```javascript
const [user, setUser] = useState({ name: '', email: '' });

// ✅ 正しい方法
setUser({ ...user, name: 'John' });
// または
setUser(prevUser => ({ ...prevUser, name: 'John' }));
```

2. **フォームの状態管理**: 入力フィールドの値をuseStateで管理
3. **条件付きレンダリング**: 状態に基づいてUIの表示を切り替え

## 気づいたこと

- useStateは非同期で動作するため、状態更新後すぐに新しい値にアクセスできない
- 関数型更新を使用すると、前の状態を確実に参照できる
- 複雑な状態管理にはuseReducerの使用を検討すべき

## 今日のコード例

```javascript
import React, { useState } from 'react';

function TodoApp() {
  const [todos, setTodos] = useState([]);
  const [input, setInput] = useState('');

  const addTodo = () => {
    if (input.trim()) {
      setTodos(prevTodos => [...prevTodos, {
        id: Date.now(),
        text: input,
        completed: false
      }]);
      setInput('');
    }
  };

  const toggleTodo = (id) => {
    setTodos(prevTodos => 
      prevTodos.map(todo => 
        todo.id === id 
          ? { ...todo, completed: !todo.completed }
          : todo
      )
    );
  };

  return (
    <div>
      <input 
        value={input}
        onChange={(e) => setInput(e.target.value)}
        placeholder="新しいタスクを入力"
      />
      <button onClick={addTodo}>追加</button>
      <ul>
        {todos.map(todo => (
          <li 
            key={todo.id}
            onClick={() => toggleTodo(todo.id)}
            style={{ textDecoration: todo.completed ? 'line-through' : 'none' }}
          >
            {todo.text}
          </li>
        ))}
      </ul>
    </div>
  );
}

export default TodoApp;
```

## まとめ

useStateはReactの状態管理の基礎となる重要なフックです。配列やオブジェクトの状態を更新する際は、イミュータブルな更新を心がけることが大切です。これにより、Reactが適切に再レンダリングを検知し、パフォーマンスの最適化が行われます。
